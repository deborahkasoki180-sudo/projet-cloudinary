# Projet Web - Intégration Cloudinary

Ce projet est une page web responsive simple conçue dans le cadre d'un travail académique. Il utilise **Cloudinary** pour l'hébergement et l'optimisation des images de la galerie.

## Fonctionnalités
- Galerie d'images hébergées à distance sur Cloudinary.
- Mise en page responsive adaptée aux téléphones et écrans d'ordinateurs.

## Technologies utilisées
- HTML5 & CSS3
- Cloudinary (Gestion et hébergement des médias)
- Git & GitHub (Contrôle de version)
